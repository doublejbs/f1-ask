# 28. 뉴스 탭 — 경기 전후 소식을 한데 모은다

## 배경

세컨드 스크린은 "지금 무슨 일이 일어나는지"를 보완한다(docs/19). 그런데 팬이 알고 싶은 것은
경기 중만이 아니다 — **경기 전후**에도 있다:

- 경기 결과·리뷰
- 규정/규칙 변경 (FIA 기술지침·페널티 판정·차기 시즌 규정)
- 팀별 신규 업데이트 (업그레이드 패키지·드라이버 라인업·파워유닛)

지금은 이런 소식이 앱에 없다. 팬은 앱을 닫고 뉴스 사이트·유튜브·SNS 를 각각 돌아다닌다.
**뉴스 탭은 그 흩어진 소스를 한 화면에 모은다.**

## 3번째 탭을 뉴스로 — AI 는 경기 탭에 남긴다

현재 하단 탭은 경기 / 기록 / **AI**다. AI 탭(`AskAiTabView`)은 두 역할을 한다:

1. **데스크톱**: 경기 콘솔 옆 2컬럼으로 상시 노출 (`LiveDashboardView` 의 `lg:grid`)
2. **모바일**: 탭투애스크(`switchToAskWithQuestion`)의 목적지 — 순위·이벤트를 탭하면 질문이
   프리필된 채 이 탭으로 전환

그래서 **AI 탭을 그냥 지우면 모바일에서 AI 질문 경로가 사라진다.** 사용자 관찰("race 탭에서
AI 질문을 하니까")은 데스크톱 기준으로는 맞다. 해법:

- **AskAiView 를 경기 탭에 귀속시킨다.** 데스크톱 2컬럼은 그대로(경기 | AI). 모바일에서는
  경기 탭 하단에 AskAiView 를 둔다 — 화면 전환 없이 같은 탭에서 질문한다.
- **탭투애스크**는 탭 전환 대신 경기 탭의 AskAiView 로 프리필 신호만 보낸다.
- 비게 된 3번째 탭 슬롯을 **뉴스**가 차지한다: 경기 / 기록 / 뉴스.
- 대화 상태는 지금처럼 언마운트 없이 보존한다(display 로만 숨김).

## 설계

### 아키텍처: 서버 수집·캐시, 클라이언트는 구독 (poller 패턴)

라이브 데이터(docs/16)·아카이브(docs/17)와 같은 원칙이다.

```
[스케줄 함수 or 서버 라우트]
  → 소스별 fetch (RSS · YouTube API)
  → NewsItem 공통 모델로 정규화 · 중복 제거 · 분류 · 정렬
  → Firestore/캐시
                     → 클라이언트가 구독/조회해 렌더
```

- **API 키는 클라이언트에 없다.** Secret Manager 로 서버에만 둔다(`OPENF1_*`·`GEMINI_*` 와
  같은 방식). 뉴스 소스 키도 같다.
- **고정 비용**: 수집은 시청자 수와 무관하다(라이브 폴러와 같은 근거, docs/10).
- **결정론적 코어**: 분류·중복 제거·정렬은 규칙으로 한다. 요약·번역만 선택적으로 LLM
  (docs/19 §결정론적 코어, 확률적 엣지). 비용을 고려해 MVP 에선 LLM 없이 원문 헤드라인.

### 공통 모델 `NewsItem`

```ts
enum NewsSourceKind { Article, YouTube, Instagram, Facebook }
enum NewsCategory { Result, Rule, TeamUpdate, General }

type NewsItem = {
  id: string;              // 소스 URL 해시 등 안정적 결정론 키 (중복 제거용)
  kind: NewsSourceKind;
  category: NewsCategory;
  title: string;
  summary: string | null;  // 발췌(원문 전문 아님 — 저작권)
  url: string;             // 외부 원문 링크
  thumbnailUrl: string | null;
  sourceName: string;      // "The Race", "F1 공식" 등
  publishedAt: string;     // ISO
  lang: string;            // 원문 언어
};
```

### 데이터 소스 — 현실 제약을 스펙에 못박는다

| 소스 | 방법 | 현실성 | 결정 |
|---|---|---|---|
| 뉴스 기사 | RSS (Formula1.com · The Race · Autosport · Motorsport) | 🟢 무료·안정·ToS 친화 | **MVP 1순위** |
| YouTube | Data API v3 (키·쿼터) | 🟢 공식/팀 채널 uploads | MVP 포함(키 필요) |
| 규정 변경 | FIA 문서 + 기사 키워드 분류 | 🟡 구조화 피드 없음 | 기사에서 분류 |
| Instagram/Facebook | Meta Graph API | 🔴 **임의 공개 계정 피드 수집 불가** (본인 소유 비즈니스 계정만). 스크래핑은 ToS 위반·취약 | oEmbed 임베드/링크 큐레이션 |
| X (트위터) | API 유료·제한 | 🔴 유사 | 링크 큐레이션 |

**핵심 제약**: IG/FB/X 는 "전체 피드 자동 수집"이 법적·기술적으로 불가하다. 자동 수집의
현실 축은 **RSS 기사 + YouTube**이며, SNS 는 **특정 게시물 oEmbed 임베드나 공식 계정 링크
카드**로 큐레이션한다(수집이 아니라 링크). 이 한계를 UI 에서 정직하게 드러낸다.

### Mock 뉴스 소스 — 오프라인·개발에서 동작

앱 전체가 mock 모드로 외부 의존 없이 도는 원칙(docs/01)을 따른다. `MockNewsSource` 가
결정론적 픽스처 `NewsItem[]` 을 돌려준다. `NewsSource` 인터페이스 뒤에 두어 라이브(RSS/YouTube)
소스와 교체한다. 덕분에 탭·정렬·분류·UI 를 네트워크 없이 테스트/검증한다.

### 분류·정렬 (결정론)

- **분류**: 소스 종류(YouTube→영상) + 제목/카테고리 키워드 규칙. 애매하면 General.
- **정렬**: `publishedAt` 내림차순. 같은 시각은 sourceName·id 로 안정 정렬.
- **중복 제거**: `id`(URL 기반) 기준. 여러 소스가 같은 기사를 실으면 하나만.

### UX

- 상단 필터 칩: `전체 | 결과 | 규정 | 팀 | 영상 | 소셜`
- 카드: 소스 배지 · 썸네일 · 제목 · 상대 시각 · 카테고리. 탭하면 **외부 브라우저로 원문**
  (앱 링크 안전 규칙: 외부 링크는 새 탭/브라우저로, 자동 동작 없음)
- **저작권**: 헤드라인 + 짧은 발췌 + 링크만. 원문 전문 복제 금지(전역 저작권 규칙과 일치).
- 로딩/빈/오류 상태를 구분(아카이브 패턴 재사용).
- i18n en/ko/ja: 크롬 문구만 번역. 기사 제목은 원문 언어(선택적 LLM 번역은 이후).
- 터치 타깃 44pt.

## 범위 밖

- IG/FB/X **전체 피드 자동 수집**(불가 — §데이터 소스). 큐레이션 링크/임베드까지.
- 앱 내 코멘트·좋아요 등 소셜 상호작용.
- 뉴스 본문 전문 렌더(저작권) — 발췌 + 외부 링크까지.
- LLM 요약·번역·개인화 추천 — 이후 단계.
- 푸시 알림.

## 단계

- **MVP**: 3번째 탭을 뉴스로 교체 + AI 를 경기 탭으로 이전. `NewsItem` 모델 · 분류/정렬/중복
  제거(결정론, 단위 테스트) · `MockNewsSource` 로 렌더되는 뉴스 탭 UI · i18n 3로케일.
  라이브 RSS/YouTube 소스는 같은 인터페이스 뒤에 붙일 자리만 마련.
- **이후**: RSS/YouTube 라이브 소스 + 서버 캐시/수집 함수 · SNS oEmbed 큐레이션 ·
  LLM 요약/번역 · 카테고리별 구독.

## 수용 기준

1. 하단 탭이 경기 / 기록 / **뉴스** 3개다. AI 탭 슬롯이 뉴스로 대체된다.
2. **AI 질문 경로가 유지된다** — 데스크톱 2컬럼 유지, 모바일은 경기 탭에서 질문. 탭투애스크가
   경기 탭 AskAiView 로 프리필된다. 대화 상태는 탭 전환에도 보존된다.
3. 뉴스 탭이 `MockNewsSource` 로 오프라인에서 렌더된다(외부 네트워크·키 없이).
4. `NewsItem` 이 소스 종류·카테고리별로 분류되고, 시각 내림차순 + 안정 정렬되며, id 로 중복이
   제거된다 — 도메인 단위 테스트로 고정.
5. 필터 칩(전체/결과/규정/팀/영상/소셜)이 목록을 걸러낸다.
6. 카드 탭이 외부 원문을 **새 탭/브라우저로** 연다. 본문 전문을 복제하지 않는다(발췌+링크).
7. 라이브 소스(RSS/YouTube)는 `NewsSource` 인터페이스 뒤에 교체 가능하게 분리된다. API 키는
   서버에만(Secret Manager). IG/FB/X 전체 수집을 시도하지 않는다.
8. i18n en/ko/ja, 44pt 터치 타깃, 로딩/빈/오류 상태.
